# 01 · 游戏设计总案

## 1. 游戏概念

**《原始纪元》** —— 你是被"永夜诅咒"笼罩的原始部落最后的首领。每个白天，你带领部落采集、狩猎、建造、研究、驯兽、探索；每个夜晚，饥饿的兽群与夜魔从黑暗中扑向部落中心的**长明篝火**。篝火熄灭，部落灭亡。撑过 15 个昼夜、集齐三件远古神器，你就能打开梦魇之门，反过来讨伐诅咒之源——**梦魇之主**，终结永夜。

- **视角**：2D 俯视角（带轻微伪 2.5D 层次感）
- **操作**：WASD 移动 + 鼠标瞄准/攻击 + 空格翻滚 + B 建造 + T 科技 + Tab 背包
- **单局**：15 昼夜通关（约 60~90 分钟），死亡即一局结束（局外成长保留）
- **通关后**：无尽模式（无限夜数，全球滚雪球式增强，挑战最高存活夜数）

## 2. 《猛鬼宿舍》机制拆解与移植映射

《猛鬼宿舍》上瘾的本质是四件事，本作全部继承并原始时代化：

| 猛鬼宿舍机制 | 本质 | 本作映射 |
|---|---|---|
| 床自动产金币 | **挂机经济，滚雪球** | 长明篝火每秒产出"火种"（主货币），升级篝火提高产出与照亮范围 |
| 门/墙有血量、花钱升级 | **防线即血条，钱→安全感** | 栅栏→木墙→石墙→骨墙四级防线，可修理可升级；墙被撞时全屏震动+音效制造紧迫感 |
| 商店买武器/道具 | **消费即成长** | 长老图腾商店：武器、陷阱、仆从、祝福，白天黑夜均可购买 |
| 鬼越来越强、砸门压迫感 | **递增威胁，倒计时张力** | 兽潮威胁值逐夜指数增长；夜魔每 5 夜以新形态登场；黄昏有"今晚敌情预告" |
| 苟到时间结束 or 买神器反杀 | **从猎物到猎人的翻转** | 集齐 3 件神器后第 15 夜可主动进入梦魇之门反杀 Boss，完成"猎物→猎人"的爽感闭环 |

**在此骨架上做加法**（这正是"丰富不单一"的关键）：猛鬼宿舍只有"守"，本作加入**白天的采集/探索/驯养/村民管理**，让玩家在"守"与"拓"之间做取舍——白天走得越远收获越大，但离家越远、夜晚准备越仓促。

## 3. 设计支柱（所有设计决策的裁决标准）

1. **滚雪球经济**：任何投入（篝火、村民、科技）都要在 1~2 个昼夜内看得到回报，数值成长曲线要"肉眼可见地变强"。
2. **昼夜张力**：白天是倒计时的贪婪（多采一点还是早点回防？），夜晚是心跳的守护（修墙还是补刀？）。永远让玩家觉得时间不够。
3. **系统交织不孤立**：每个系统至少与两个其他系统联动（例：天气影响采集与敌潮；驯养的战狼白天帮狩猎、夜晚帮守家；村民既是产能也是可能被夜魔掳走的软肋）。
4. **每晚一个钩子**：每个夜晚结束都必须给玩家一个"再来一晚"的理由——三选一图腾祝福、新科技解锁、明晚敌情预告、Boss 倒计时。

## 4. 核心循环

```
┌─────────────────────────────────────────────────────┐
│  白天 (约4分钟)                                       │
│  采集/狩猎/钓鱼 → 建造/升级防线 → 研究科技 →           │
│  探索新区域(洞穴壁画/稀有资源) → 招募村民/驯养野兽      │
└──────────────────────┬──────────────────────────────┘
                       ▼
│  黄昏 (30秒)：敌情预告(种类/数量/方向) + 最后备战       │
                       ▼
┌─────────────────────────────────────────────────────┐
│  夜晚 (约2.5分钟)                                     │
│  兽潮多波次进攻 → 亲自战斗/陷阱触发/村民与战兽协防 →    │
│  修墙抢救 → (每5夜) 夜魔Boss登场                       │
└──────────────────────┬──────────────────────────────┘
                       ▼
│  黎明结算：存活奖励 + 图腾祝福三选一(Roguelite) +       │
│  明晚威胁预告 → 回到白天                                │
```

**局内成长双轨**：资源/建筑/科技（部落变强） × 装备/祝福/驯兽（个人变强）。
**局外成长**：每局结算获得**图腾点**（按存活夜数、击杀、成就折算），解锁天赋树与新开局职业。

## 5. 一局流程节奏（15 夜编排）

| 阶段 | 夜数 | 体验目标 | 关键节点 |
|---|---|---|---|
| 教学期 | 第 1~2 夜 | 学会采集/建墙/战斗，敌人只有狼 | 第 1 夜必定轻松守住，建立信心 |
| 成长期 | 第 3~4 夜 | 解锁科技树、招募首个村民、遭遇天气 | 野猪登场（会撞墙），逼玩家升级防线 |
| **小Boss** | **第 5 夜** | 第一次心跳时刻 | 夜魔·爪形态 + 掉落神器碎片Ⅰ + 解锁洞穴区域 |
| 拓展期 | 第 6~9 夜 | 探索洞穴/沼泽、驯养、陷阱体系成型 | 第 7 夜前后随机血月（高风险高回报） |
| **中Boss** | **第 10 夜** | 压力峰值 | 夜魔·影形态（召唤蝙蝠群无视墙）+ 神器碎片Ⅱ |
| 决战期 | 第 11~14 夜 | 全系统火力全开备战，猛犸兽潮 | 第 13 夜雪季开始（食物消耗翻倍） |
| **终局** | **第 15 夜** | 猎物→猎人的翻转 | 集齐神器→主动进入梦魇之门讨伐梦魇之主；未集齐则防守"最长的夜"后进无尽模式 |

## 6. 玩家角色

- **属性**：生命、体力（冲刺/翻滚消耗）、饱食度（归零扣血）、体温（雪季/雨天流失）
- **手感规格**：攻击命中有 60ms 顿帧 + 击退 + 飘字；翻滚 0.4s 无敌帧；被击屏幕红晕 + 震动
- **开局职业**（局外解锁）：
  - **猎手**：初始弓 + 移速+10%（默认）
  - **巫医**：自带治疗图腾 + 草药效果翻倍
  - **工匠首领**：建筑费用 -20% + 初始多一个村民

## 7. 美术与音效方向（无外部素材，全程序化生成）

- **画面**：手绘感矢量像素混合风。代码绘制所有精灵（人物/野兽用几何体+描边+动画骨骼式摆动），配色随昼夜循环整体变化（清晨暖橙→正午明亮→黄昏血红→夜晚深蓝+篝火暖光圈）
- **光照**：夜晚全屏暗色遮罩 + 篝火/火把的径向暖光洞（canvas 混合模式实现），光照范围就是安全区的视觉语言——夜魔在光外只有一双红眼睛
- **粒子**：篝火火星、砍树木屑、命中血珠、雨雪、血月红雾、Boss 出场冲击波
- **音效**（Web Audio 全合成，无音频文件）：篝火噼啪、采集敲击、狼嚎（夜晚随机方位 3D 声像）、战斗鼓点 BGM（夜晚 BPM 随威胁升高）、白天骨笛环境旋律、低血量心跳声
- **UI**：石板/兽皮质感面板，图标全部代码绘制

## 8. 上瘾点设计清单（对照落实）

- [x] 挂机经济滚雪球（篝火产火种，离线也想着回来收）
- [x] 每晚黎明三选一图腾祝福（Roguelite 随机构建，每局玩法不同）
- [x] 5/10/15 夜 Boss 里程碑（清晰的短期目标）
- [x] 血月机制（双倍敌潮双倍掉落，主动赌博选项：黄昏可献祭资源"召唤血月"）
- [x] 敌情预告（已知威胁产生的备战焦虑，比未知更上瘾）
- [x] 村民有名字会永久死亡（情感沉没成本）
- [x] 局外图腾点天赋树（这局输了也有获得感）
- [x] 无尽模式排行榜（本地最高纪录，自我挑战）
- [x] 成就系统（约 20 个，如"一墙不破守过第 5 夜"）

## 9. 明确不做的（控制范围）

- 不做多人联机（单机，但架构预留接口注释）
- 不做随机地图生成（手工设计一张大地图，保证探索节奏可控；无尽模式用同图）
- 不做剧情对话树（叙事全部通过洞穴壁画碎片 + 环境讲故事）
- 第一版不做手柄支持
