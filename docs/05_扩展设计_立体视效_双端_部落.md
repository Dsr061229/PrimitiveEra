# 05 · 扩展设计：伪 3D 视效 / 双端支持 / 部落互动

> 2026-07-14 新增需求，在 01~04 基础上生效；冲突处以本文档为准。

## 1. 伪 3D 立体视效（Don't Starve 式 2.5D）

逻辑保持纯 2D 俯视，渲染制造立体感：

- **直立式精灵**：地面是俯视平面，实体（人/兽/树/建筑）以 3/4 视角"立牌"方式直立绘制，脚底对齐世界坐标
- **椭圆软阴影**：所有实体脚下绘制半透明椭圆阴影（跳跃/击飞时阴影分离，高度感）
- **Y 排序遮挡**：按 y 排序绘制，玩家可以走到树后被树冠遮挡（遮挡时轮廓半透明显形）
- **体积光影**：精灵用垂直渐变塑体积（顶亮底暗）+ 顶部受光边缘高光，受击闪白
- **云影层**：半透明云影缓慢飘过地面（视差层），白天真实感的大头
- **昼夜调色**：全屏色调渐变（晨橙→午亮→暮红→夜蓝）+ 夜间光洞遮罩
- **纵深微缩放**：树冠随风摆动、篝火光圈呼吸波动、雨雪粒子分前后两层速度

## 2. 双端支持（PC + 移动触屏，同一份代码自适应）

- **画布**：全屏自适应 + devicePixelRatio 缩放；横屏优先，竖屏提示旋转
- **输入抽象层**：逻辑只读"动作"（move/aim/attack/roll/interact），不直查设备
  - PC：WASD 移动、鼠标瞄准、左键攻击、空格翻滚、E 交互、B 建造、1~6 快捷栏、Esc 暂停
  - 触屏：左半屏虚拟摇杆移动；右侧按钮簇（攻击=自动瞄准最近敌人、翻滚、交互）；建造/科技/商店为 HUD 图标按钮；面板全部大按钮可点
- **UI 自适应**：触屏设备 UI 元素放大 1.3~1.5 倍，按钮最小 56px 命中区
- **性能自适应**：帧率 <45 自动降粒子/云影档位
- **技术决策变更**：放弃 ES Modules，改为全局命名空间 `PE` + 按序加载的普通 script 标签 —— PC 上**双击 index.html 即玩**（file:// 可用），手机端经局域网/托管访问同一目录即玩

## 3. 部落互动系统（NPC 部落）

地图上两个 NPC 部落营地，各有声望值（-100~100，跨昼夜持续）：

| 部落 | 位置/性格 | 特色 |
|---|---|---|
| **河岸部落** | 河流东岸，温和商贸 | 特产：渔网、稀有草药、黏土制品；初始声望 +10 |
| **灰烬部落** | 火山口北麓，好战贪婪 | 特产：黑曜石、战纹颜料（攻击 buff）；初始声望 -10，会索贡 |

**互动方式**（走到对方营地与首领/商人交互）：
- **贸易**：资源互换（各部落汇率不同，随声望浮动 ±20%）
- **赠礼**：赠送资源提升声望
- **雇佣**：花火种雇佣部落战士为你守夜 2 晚
- **结盟**（声望 ≥60）：Boss 夜自动派 2 名战士驰援；解锁部落专属科技/商品
- **敌对**（声望 ≤-40）：夜袭波次中混入部落战士；灰烬部落定期索贡事件（给 30 食物或声望 -30）
- **劫掠**：主动攻击其营地 → 声望 -50 立即敌对，可搜刮物资箱（高风险高回报路线）
- **随机事件**：部落使者来访（声望三选一抉择）、联合狩猎节（限时共猎盛宴）

设计意图：给"白天"再添一条策略轴（外交路线 vs 劫掠路线），并与夜晚防守联动（盟军驰援/仇敌夜袭）。

## 4. 落地文件结构（合并版，替代 03 §2 的细分结构）

```
PrimitiveEra/
├── index.html          # 入口，按序加载脚本，双击即玩
├── docs/
└── src/
    ├── core.js         # 命名空间/工具/RNG/固定步长循环/相机/空间哈希/流场寻路
    ├── input.js        # 键鼠+触屏统一动作层、虚拟摇杆
    ├── audio.js        # WebAudio 合成音效 + 程序化 BGM
    ├── data.js         # 全部数值表（对应文档02+本文档）
    ├── sprites.js      # 程序化精灵绘制（参数化人形/四足/植被/建筑/图标）
    ├── fx.js           # 粒子/光照/天气/飘字
    ├── world.js        # 时间/季节/天气/地图烘焙/资源点/迷雾/网格
    ├── player.js       # 玩家/战斗/投射物
    ├── enemies.js      # 敌人AI/Boss/兽潮导演/野生动物
    ├── systems.js      # 建造/经济/科技/村民/驯养/部落/事件/祝福/存档/局外成长
    ├── ui.js           # 即时模式UI/HUD/面板/菜单（双端自适应）
    └── main.js         # 状态机/渲染管线/胶水
```

## 5. 平衡性调整记录（2026-07-15，依据试玩反馈，以代码为准）

- **开局**：自带 2 名村民（采集者+猎人，工匠首领职业 +1 工匠）；初始资源上调（木40/石20/食30/火种60）
- **节奏**：白天 240s→360s；饥饿消耗放缓（5分钟→7分钟耗尽）
- **难度曲线**：威胁预算 30×1.35ⁿ → 6×1.4ⁿ；第 1 夜固定只来 3 头狼、第 2 夜 4 头；夜魔·爪 800→600 血
- **篝火**：商店新增「升级篝火」（50/150/400/900 火种，5 级封顶），升级即时提升产出/光圈/血量并有特效反馈；商店页显示当前产出
- **建造**：栅栏/木墙/石墙/帐篷/工作台/石坛/兽栏/瞭望塔费用全面下调；树木产出翻倍
- **驯服**：无需科技即可驯服（驯兽术改为战兽属性+25% 增益）；血量阈值 30%→50%；喂食成本减半；巨鹰只需 80 火种
- **击杀奖励**：全敌人火种赏金上调约 50%，资源掉落新增飘字反馈
- **村民生存**：血量 60→80、猎人攻击 8→12、**篝火光圈内村民受伤减半**（光=安全的设计语言）
- **地图**：边界改为带噪声起伏的环岛海洋+沙滩过渡（替代硬墙）；新增 8 个探索宝箱（随机火种/物资/星陨铁）与蘑菇圈资源点（森林/沼泽）
- **修复**：近战攻击角度判定反向的严重 bug（原先只能命中身后目标）
- **修复(第二轮)**：驯服野兽调用了不存在的函数导致游戏主循环冻结；主循环加 try/catch 保护，任何帧异常不再冻结游戏
- **修复(第二轮)**：卡墙三源头——建造不能再压在人/兽身上、击退不再推人进墙/水、玩家被困时自动弹回最近可行走点
- **新增**：拆除建筑功能——PC 右键点建筑直接拆除；建造面板新增「拆除模式」卡片（触屏入口）；返还 50% 材料；建造模式中右键=取消；篝火不可拆
- **修复(第三轮)**：村民后期怠工——采集搜索半径 700→1300 且以村民自身就近取材、走不到的资源点自动拉黑（黎明重置）、可采草药/黏土/蘑菇
- **修复(第三轮)**：友方寻路——村民/战兽卡墙 3 秒自动翻越（回家/干活不再被墙困死）、被砌进墙里自动脱困、门口 14px 滑入辅助（玩家同享）、友方单位彼此轻推分离不堵门
- **新增(第三轮)**：夜行捕猎——夜晚野生狼/野猪主动猎杀【黑暗中】的目标（光圈内安全，与"光=安全"一致）；修复野生动物攻速 NaN 只咬一口的 bug
