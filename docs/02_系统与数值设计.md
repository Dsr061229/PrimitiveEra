# 02 · 系统与数值设计

> 本文档是实现时的数值基准。所有数值集中放在 `src/data/` 配置文件中，方便调平衡。
> 时间基准：1 游戏昼夜 = 白天 240s + 黄昏 30s + 夜晚 150s ≈ 7 分钟。

## 1. 资源系统（11 种）

| 资源 | 获取方式 | 主要用途 | 稀有度 |
|---|---|---|---|
| 火种 🔥 | 篝火自动产出、击杀、结算 | 主货币：商店、升级、修理 | 通货 |
| 木材 | 砍树 | 建筑、工具、燃料 | 常见 |
| 石头 | 采石 | 建筑、工具升级 | 常见 |
| 食物 | 打猎/采浆果/钓鱼/烤肉 | 饱食度、村民口粮、驯养 | 常见（雪季紧缺） |
| 皮毛 | 猎杀野兽 | 护甲、保暖、帐篷 | 较常见 |
| 燧石 | 采石副产物、河滩 | 武器刃部、箭矢 | 较常见 |
| 骨头 | 猎杀大型兽 | 高级建筑、骨墙、骨矛 | 中等 |
| 黏土 | 河岸采集 | 制陶（储物/火油罐） | 中等 |
| 草药 | 森林/沼泽采集 | 治疗、解毒、巫术 | 中等 |
| 黑曜石 | 洞穴/火山口 | 顶级武器 | 稀有 |
| 星陨铁 | 陨石事件、Boss 掉落 | 神器合成、终极装备 | 极稀有 |

- 采集节点有限但每天黎明部分刷新（树桩 3 天重生，浆果丛 1 天）。
- 背包 12 格 + 每格叠加上限，逼玩家建**储物陶罐**（部落公共仓库），被毁会掉落资源——防线破了不只丢血还丢家底。

## 2. 采集与工具

工具三级：**燧石级 → 骨制级 → 黑曜石级**。每级采集速度 ×1.5、可开采更高级节点（如骨镐才能挖黑曜石）。

| 动作 | 基础耗时 | 产出 |
|---|---|---|
| 砍一棵树 | 4 下（每下 0.6s） | 木材 ×4~6 |
| 采石 | 5 下 | 石头 ×3~5，20% 燧石 ×1 |
| 采浆果 | 1s | 食物 ×2 |
| 钓鱼 | 3~6s 随机（有节奏判定小游戏：浮标下沉时点击） | 食物 ×3，10% 出稀有鱼（卖高价火种） |
| 打猎 | 战斗 | 食物+皮毛+骨头（按兽种） |

## 3. 经济：篝火与火种

- 篝火产出公式：`火种/秒 = 0.8 × 篝火等级 × (1 + 0.1 × 在光照圈内的村民数)`
- 篝火 5 级：升级费用 50/150/400/900 火种+材料；每级照亮半径 +60px、血量 +300
- **篝火需要燃料**：每 60s 消耗木材 1（等级越高消耗越多），断燃料产出减半且光圈收缩——夜晚断燃料是灾难，形成"木材永远不嫌多"的压力
- 击杀奖励：小型兽 3~5 火种，大型兽 15~30，Boss 300+
- 黎明结算：`20 + 10×夜数 + 未受损防线奖励`

## 5. 科技树（研究石坛，花火种+材料+真实时间研究）

三分支各 6 项，同时只能研究一项（研究 30~90s），逼玩家做优先级取舍：

**生存分支**：烤肉架 → 草药学(治疗药) → 制陶(储物+火油罐) → 织布保暖(抗雪季) → 渔网(自动产鱼) → 丰收图腾(采集×1.5)
**战争分支**：骨制武器 → 陷阱工艺 → 图腾塔 → 黑曜石开锋 → 图腾塔Ⅱ(冰冻弹) → 战争号角(夜晚全体攻击×1.3)
**巫术分支**：驯兽术 → 治疗图腾(光圈内回血) → 视界术(地图显示夜袭路线) → 血月仪式(主动召唤血月) → 唤灵术(阵亡村民化为灵魂战士一夜) → 梦魇之钥(**通关必研**，合成神器用)

## 8. 兽潮生成（威胁预算制）

```
夜晚威胁预算 = 30 × 1.35^(夜数-1) × 难度系数 × 血月系数(2.0)
```

- 预算按敌人威胁值"购买"敌群，按夜数解锁池子随机组合 → 每晚成分不同但强度可控
- 每夜 2~4 波，波间隔 20~30s；进攻方向 1~3 个（黄昏预告会显示方向箭头与主力兵种剪影）
- 兽潮 AI 目标优先级：篝火 > 挡路防线 > 村民 > 玩家（狼/蛇例外，见图鉴）
- 寻路：流场寻路（以篝火为目标），撞到墙则就地攻击墙

## 10. 村民系统

- 上限 = 2 + 帐篷数×2（封顶 8）；获取：随机事件"流浪原始人"投靠、商店高价招募、无尽模式救援
- 每人随机：名字（原始风随机音节，如"乌拉""格朗"）+ 性格词条（勤劳:产出+15% / 胆小:夜晚躲帐篷 / 勇猛:战斗+25% / 贪吃:口粮×2）
- 职业指派：**采集者**（自动采集指定资源）/ **猎人**（白天猎小动物、夜晚持矛守卫）/ **巫师**（加速研究、夜晚给玩家套盾）/ **工匠**（自动修墙，修理费 -50%）
- 每人每天消耗食物 2；断粮士气崩溃罢工
- **会永久死亡**；夜魔系敌人会尝试"掳走"倒地村民（拖拽出光圈，玩家可追击救回）——制造夜晚救人的高光时刻

## 13. 天气与季节

- 季节：第 1~6 夜绿季 → 第 7~12 夜雨季 → 第 13 夜起雪季（食物消耗×2、体温机制激活、河面结冰可走捷径）
- 天气（每天随机，黄昏预告明天天气）：
  - **晴**：无修正
  - **雨**：篝火产出 -25%、敌人移速 -15%、钓鱼产出 +50%
  - **雾**：视野半径 -40%、敌情预告失效（最恐怖的夜）
  - **血月**（第 6 夜后 15% 概率，或巫术主动召唤）：威胁×2、掉落×2、必出稀有敌人——赌徒选项

## 15. 黎明三选一图腾祝福（Roguelite 构建，每局 build 不同）

词条池约 24 条，按稀有度加权，示例：

- 普通：采集+20%｜移速+8%｜每夜开始回满血｜箭矢造价减半｜修理效率×1.5
- 稀有：篝火产出+30%｜陷阱伤害×1.5｜翻滚后下次攻击必暴击｜村民攻击+40%｜光圈+25%
- 史诗：击杀 10% 概率掉火种翻倍｜每夜首个被破坏的墙立即免费复原｜战兽死亡改为重伤 1 次/局｜黑夜中你也算"在光圈内"

## 17. 局外成长（图腾点天赋树）

- 图腾点 = 存活夜数×10 + Boss 击杀×50 + 成就一次性奖励
- 天赋树三列各 5 层（花费递增）：**开拓**（初始资源/背包/移速）、**守护**（篝火血量/墙费用/修理）、**血脉**（解锁巫医与工匠首领职业/祝福三选一变四选一/开局带战狼）
- 成就约 20 个（本地保存）：首次通关、无伤守夜、驯服全部战兽、无村民死亡通关、无尽 20 夜……
