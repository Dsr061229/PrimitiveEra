# 04 · 开发路线图与落地清单

> **给下次开发会话的指令**：按本清单从 P0 到 P2 顺序实现，数值一律引用文档 02，架构一律遵循文档 03。每完成一个 P 级即可运行验证一次。若单次会话写不完，按 §4 裁剪预案收尾，保证交付的永远是"可玩的完整循环"而非"半成品的全部系统"。

## 1. P0 —— 核心可玩循环（没有它就不是游戏）

- [ ] 工程骨架：index.html / start.bat / 目录结构 / 固定步长循环 / 输入 / 摄像机
- [ ] 地图与地面渲染（先只做营地+森林+河滩三区域，其余区域地形画出但资源后补）
- [ ] 玩家：移动/翻滚/属性条（血量/体力/饱食）/背包/木棒攻击 + 打击感全套（顿帧/击退/飘字/闪白/震屏）
- [ ] 采集：树/石/浆果三种节点 + 工具等级判定
- [ ] 建造模式：栅栏→木墙→石墙 + 门 + 修理/升级 + 网格放置 UI
- [ ] 长明篝火：产火种/燃料消耗/光圈/被毁败北
- [ ] 昼夜循环：时钟环 UI + 色调渐变 + 夜间光照遮罩
- [ ] 兽潮导演：威胁预算公式 + 波次调度 + 敌情预告（先支持狼/头狼/野猪三种敌人 + 完整 AI：流场寻路/攻墙/特性）
- [ ] 图腾商店（基础货架：矛/弓/箭/修理锤/食物）
- [ ] 黎明结算：奖励 + 三选一祝福（先接入 8 个词条）
- [ ] HUD：资源栏/快捷栏/小地图/预警箭头
- [ ] 基础音频：篝火/敲击/命中/狼嚎/昼夜两首程序化 BGM
- [ ] 黎明自动存档 + 主菜单/失败结算
- [ ] **P0 验收：能完整游玩第 1~5 夜，守不住会输，滚雪球成长成立，有打击感有氛围**

- [ ] 敌人图鉴补全（毒蛇/剑齿虎/蝙蝠群/巨熊/沼泽魔裔/岩甲犀/猛犸/夜魔之眼）
- [ ] 第 5 夜 Boss 夜魔·爪 + 第 10 夜 夜魔·影 + 神器碎片线
- [ ] 陷阱五种 + 图腾塔（自动攻击塔）体系
- [ ] 村民系统：招募/职业/性格/口粮/永久死亡/被掳走救援
- [ ] 驯养系统：四种战兽
- [ ] 武器补全（骨锤/黑曜石矛/星陨弓/投掷物）+ 工作台打造
- [ ] 地图全区域开放：洞穴/沼泽/雪山/火山口 + 迷雾 + 壁画碎片×6 + 恐惧值机制
- [ ] 天气四种 + 季节三段 + 体温机制
- [ ] 随机事件表八项
- [ ] 血月机制（随机+主动召唤）
- [ ] 祝福词条池补满 24 条
- [ ] **P1 验收：第 1~14 夜内容全部就位，每晚体验有明显差异**

## 3. P2 —— 终局与打磨（上瘾与卖相）

- [ ] 第 15 夜双结局：梦魇之门 Boss 战（三阶段梦魇之主）/ 极限防守夜
- [ ] 无尽模式 + 本地最高纪录
- [ ] 局外成长：图腾点结算 + 天赋树三列 + 三职业
- [ ] 成就系统 ~20 个
- [ ] 音频打磨：BGM 威胁联动/立体声像/心跳/Boss 专属鼓点
- [ ] 视觉打磨：粒子全套（雨雪/血月红雾/Boss 冲击波）/光圈呼吸/精灵动画细节
- [ ] 教学引导：第 1 天上下文提示气泡（不做强制教程）
- [ ] 设置面板：音量/震屏开关/语言留位
- [ ] 存档导入导出
- [ ] build.js 单文件分发版 +（可选）Electron 打包 exe
- [ ] **P2 验收：从主菜单到通关再到无尽模式全流程无断点，愿意"再来一晚"**

## 4. 裁剪预案（若一次会话写不完，按此顺序砍，砍到哪都能玩）

1. 先砍：Electron 打包、成就、存档导入导出、教学气泡
2. 再砍：无尽模式、天赋树（图腾点先只记录数字）、第 15 夜 Boss 战（保留极限防守结局）
3. 再砍：驯养四兽减为战狼一种、事件表减为四项、雪山/火山口区域
4. **底线不可砍**：P0 全部 + 科技树 + 第 5/10 夜 Boss + 村民 + 血月——这是"猛鬼宿舍式上瘾骨架 + 丰富度下限"

## 5. 已确定的关键决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 技术栈 | 原生 Canvas 2D + Web Audio，零依赖零素材 | 一次性落地可靠性最高，写完即玩 |
| 美术 | 全程序化绘制 | 无素材依赖；风格统一由绘制规范保证 |
| 地图 | 手工设计固定图 | 探索节奏可控，工期可控 |
| 单局结构 | 15 夜通关 + 无尽 | 有明确终点的上瘾比无终点更健康也更有动力 |
| 存档 | 仅黎明快照 | 防夜战 S/L 滥用，保留"关机续玩" |
| 联机 | 不做，留确定性基础 | 控制范围 |

## 6. 风险清单

| 风险 | 缓解 |
|---|---|
| 程序化精灵画风不统一/丑 | 严格执行 draw_sprites 绘制规范（2px 描边/大色块/统一调色板常量）；先画 5 个核心精灵定调再批量 |
| 数值失衡（太难/太简单） | 全数值集中 data/balance.js；按文档 02 §16 达标线自测第 1/5/10 夜 |
| 一次会话代码量过大 | 严格 P0→P1→P2 顺序 + 裁剪预案；数据文件先行（配置即文档） |
| Canvas 性能（兽潮+粒子+光照） | 空间哈希/对象池/离屏烘焙已入架构；同屏实体预算 300 |
