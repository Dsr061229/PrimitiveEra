# 原始纪元 · Primitive Era

> 一款单机 PC 生存游戏：白天采集、建造、探索、壮大部落，夜晚守护篝火抵御兽潮与夜魔。
> 玩法骨架参考《猛鬼宿舍》的"经济滚雪球 + 防线守卫 + 越夜越强 + 终局反杀"，并扩展为内容丰富的原始时代部落生存体验。

## 当前状态

**实现中。** 设计文档齐备（含 05 扩展：伪 3D 视效、PC+移动双端、部落互动），代码按 docs/04 清单落地。

**运行方式**：PC 上直接双击 `index.html`（或任意静态服务器托管）；手机端将本目录用局域网静态服务器托管后浏览器访问，横屏游玩。

## 一句话概览

- **类型**：俯视角 2D 生存 + 基地防守 + 轻 Roguelite
- **平台**：Windows PC（HTML5 Canvas 技术栈，双击即玩，可打包 Electron 成 exe）
- **一局时长**：约 60~90 分钟（15 个昼夜通关），通关后开启无尽模式
- **核心张力**：白天永远不够用，夜晚永远比你想的更凶
